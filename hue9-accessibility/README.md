# Hue9 Accessibility

Accessibility information for **Hue9: Color Sudoku**.

The site is a dependency-free static page designed for GitHub Pages. It documents:

- Symbol Mode and Differentiate Without Color
- VoiceOver
- Larger Text / Dynamic Type
- Reduce Motion
- Increased Contrast and appearance options
- Zen Mode

It is localized in the same six interface languages as the app:
English, Spanish, German, French, Japanese and Simplified Chinese.

## Publish with GitHub Pages

1. Create a public repository named `hue9-accessibility`.
2. Push the contents of this folder to the repository’s default branch.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the default branch and the root (`/`) folder.

The final URL will be:

`https://davidcafor.github.io/hue9-accessibility/`
